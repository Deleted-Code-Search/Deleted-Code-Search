## 배운 것
- 필터 없이 추출하면 파일 이동 한 커밋이 FULL_FUNCTION을 지배한다. requests 최근 300커밋에서 242건 중 235건(97.1%)이 커밋 d63e94f 하나였다
- 오래된 저장소는 데이터가 많은 구간과 이유가 기록된 구간이 어긋날 수 있다. requests는 FULL_FUNCTION이 2011–2017에 몰렸고 2011–2013 표본의 PR 연결은 50%였다. 다만 표본 10건·판정자 1인의 사전 탐색이라 근거가 얇다
- GitHub API는 같은 URL에서도 간헐적으로 500을 낸다. 수백 회 연속 호출하는 스크립트는 재시도가 없으면 한 번의 오류로 전체가 끝난다
