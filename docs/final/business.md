# 시장성·수익모델·사업화 계획 요약

포스터에 그대로 옮겨 쓸 수 있게 결과보고서 [3장](report.md#3-시장성과-수익모델)·[4장](report.md#4-사업화-계획과-실현-가능성)을 줄였다. 숫자는 모두 측정 보고서 값이다. 사업 내용은 **계획**이고, 고객 인터뷰·시장 규모 조사·가격 산정은 아직 하지 않았다.

**한 줄:** 기존 도구는 내 코드베이스의 죽은 코드를 청소합니다. 기존 검색은 지워진 문자열을 찾습니다. 우리는 오픈소스 전체에서 남들이 왜 지웠는지를 배웁니다.

## 누가 쓰나

| 고객 | 문제 | 주는 것 |
|---|---|---|
| 시니어 리뷰어 없는 개발자·소규모 팀·학생 | 내 코드가 나중에 지워질 패턴인지 물어볼 사람이 없다 | 비슷한 코드를 남들이 왜 지웠는지 검색 |
| AI 코딩 도구로 짠 코드를 검증하려는 기업 | AI 도구는 살아남은 코드로 학습해, 나중에 지워질 코드를 낼 수 있다 | AI가 낸 코드와 유사한 삭제 이력·이유 분포 |
| 연구자 | 삭제 이유 연구마다 데이터를 새로 모은다 | 공개 데이터셋, 사람 확정 라벨 500건 |

| 수익원 | 무엇을 파나 | 과금 |
|---|---|---|
| VS Code 플러그인 구독 | 코드를 쓰는 순간 유사 삭제 이력 경고 | 사용자당 월 구독 |
| 기업 사내 저장소 분석 (B2B SaaS) | 사내 삭제 이력·이유 통계, 설치형 포함 | 조직·저장소 규모별 계약 |
| 검색·진단 API 유료 호출 | 코드 리뷰 봇·AI 코딩 도구가 부르는 삭제 이력 조회 | 호출 수 |
| 데이터셋 상업 라이선스 | 공개판에 없는 개선 라벨·정기 갱신·추가 언어·지원 | 판본·연 단위 계약 |

공개 데이터셋(CC BY 4.0)과 기본 검색은 무료로 둔다. CC BY 4.0은 상업 이용도 허용하므로 유료판이 파는 것은 권리가 아니라 품질과 갱신이다. 코드 스니펫은 유료판에서도 원 저장소 라이선스를 따른다.

## 솔직한 약점

- **사용자 효용을 잰 적이 없다.** 개발자 10명 평가를 하지 않아 지불 의사도 모른다. 2단계 전에 먼저 잰다.
- **정확도.** 게이트 2 60.0% 미달. 개선값 8종 73.0% / 4묶음 85.0%는 같은 test를 보며 고른 값이다. 필터 정밀도는 76.0%로 목표 90%에 못 미친다.
- **규모를 키우면 무료로는 안 된다.** 개선 분류기를 전체에 적용하려면 약 360만 회 호출이 필요하다. 2단계의 첫 비용 항목이다.
- **학습 저장소 밖으로 일반화되지 않았다.** 신규 80개에서 모델만 분류기가 LLM 포함과 같은 구체적 이유를 낸 건이 0/606이다.
