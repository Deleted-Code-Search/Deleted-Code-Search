### 2026-09-12 — 맥락 결합 붙는 비율 (#6)

**무엇을 잰 건가.** 커밋 하나에 PR·이슈·리뷰 코멘트가 실제로 붙는 비율. 위 표의 "이유 회수율"과는
다르다. 회수율은 라벨링 후 EXPLICIT+INFERRED 비율이고, 이건 그 **상한**이다. 맥락이 안 붙으면
이유를 적을 텍스트 자체가 없다.

**조건.** §4.3 초기 후보 10개 저장소 × 최근 커밋 20건(병합·봇 제외) = 194건.
`python -m pipeline.context --repo <repo> --sample 20`. 커밋 자체는 삭제 커밋이 아니다 (#5 미완).

| 저장소 | 표본 | PR | 이슈 | 리뷰 | 하나라도 |
|---|---|---|---|---|---|
| pydantic/pydantic | 20 | 100% | 70% | 40% | 100% |
| celery/celery | 20 | 95% | 45% | 50% | 100% |

**해석 — 저장소마다 이슈 참조 관행이 다르다. 하나의 규칙으로는 못 읽는다.**
- `#숫자` (대부분) / `GH-숫자` (pandas: 20건 중 19건이 이 형식, `#숫자`는 0건) /
  Trac 티켓 (django: `Fixed #36933` 의 번호가 GitHub 에 없음, 404) / PR 미사용 (sqlalchemy: 20건 전부
  `Change-Id:` — Gerrit 으로 리뷰하고 GitHub 은 미러)
- `GH-` 파싱을 넣기 전 pandas 이슈 회수는 0% 였다. 저장소 20개를 확정할 때(#1) 참조 형식을 함께 봐야 한다.

**해석 — "참조가 있다"와 "이유를 가져왔다"는 다르다.** 선정 CSV(#1)의 `issue_ref_ratio` 와 대조하면:

| 저장소 | 선정 CSV `issue_ref_ratio` | 실제 이슈 회수 | 차이의 원인 |
|---|---|---|---|
| django/django | 0.733 | 0% | `#번호`가 Trac 티켓. GitHub 에 없다 |
| pydantic/pydantic | 0.833 | 70% | 대체로 일치 |
| encode/httpx | 0.000 | 0% | 일치 |

django 는 선정 점수 1위(0.8683)인데 이슈 본문을 하나도 못 가져온다. §4.3 ④(이슈 참조 관행)를
"참조가 있나"가 아니라 "그 참조로 본문을 가져올 수 있나"로 보는 편이 게이트 1 예측에 맞다.
django 는 리뷰 코멘트 70%(최고)가 그 손실을 일부 메운다.

**교차 검증 (독립 구현 2개가 같은 값).** 선정 CSV 의 `pr_ratio` 와 맥락 결합의 PR 회수율:
sqlalchemy 0.033↔0%, flask 0.267↔25%, django 0.933↔90%, scikit-learn/pydantic/pandas/requests/fastapi
1.000↔100%. `pipeline/select_repos.py` 와 `pipeline/context.py` 는 서로 다른 사람이 따로 구현했다.
