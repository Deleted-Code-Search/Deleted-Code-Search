# ADR-021: §10.6 P × A 를 연쇄 법칙으로 정식화 — A 는 의미 있는 삭제 안에서 잰다

- 날짜: **2026-10-30**
- 상태: 제안 (이 PR 승인으로 채택)
- 관련 이슈: #129, ADR-016(#91, PR #94), #89, #86
- 결정 경로: 평가 논증(§10.6) 변경이라 §13 절차를 따른다. **이슈 #129 → 팀 확인(이 PR 의 리뷰 승인으로 갈음) → 이 ADR → CHARTER §10.6 갱신.** 반대 의견은 PR 코멘트로 받는다
- 근거 문서: `docs/reports/pxa_argument.md`, 숫자 `docs/reports/pxa.json` (`python -m eval.pxa`)

## 맥락

- CHARTER §10.6 3번은 v1.14(ADR-016)부터 "P × A 수준으로 대략 추정, 정확한 결합 확률이 아니다"로 한정만 하고, 정식 관계는 별도 이슈(#129)로 남겼다.
- 게이트 2 의 A = 60.0% 는 test 100건 전체를 분모로 한 정확도다. test 는 `FULL_FUNCTION`·`KEPT` 에서 뽑았고, **의미 없는 삭제도 빼지 않고 `UNK` + `filter-miss` 로 라벨했다** (가이드 §6.3.1-3, §6.3.3). 그래서 A 는 P(C | K) 이고, P = P(M | K) 와 곱하려면 M 과 C 의 독립이 필요하다.
- 그런데 test 100건 중 확정 라벨이 `filter-miss` 인 15건이 레코드 단위로 표시돼 있다. 같은 예측으로 P(C | M, K) 를 셀 수 있다 — 49/85 = 57.6%.
- 발표 예상 질문 "왜 곱하나"(§12.3)에 답이 있어야 한다.

## 결정

1. **§10.6 의 목표량을 P(M ∧ C | K) 로 정의한다.** K = 필터 통과, M = 의미 있는 삭제(가이드 §6.3.3), C = 이유 라벨이 사람 확정 라벨과 같음(정답 `UNK` 를 `UNK` 로 맞힌 것 포함).
2. **§10.6 에 쓰는 A 는 A' = P(C | M, K) 다.** test 100건에서 확정 라벨이 `filter-miss` 인 건(`AGREED` 는 두 라벨 모두, `THIRD_PARTY` 는 고른 라벨)을 뺀 정확도. 그러면 P × A' 는 연쇄 법칙이라 **독립 가정은 필요 없다. 다만 (a) P 의 M 과 A' 의 M 이 같은 사건 (b) 두 값이 같은 모집단·가중치라는 두 가정 아래의 근사다** — P 와 A' 를 다른 표본·다른 판정으로 쟀기 때문이다. 값은 두 개를 나란히 적는다:
   - P = KEPT 전체(FULL + PARTIAL, 사전 등록 정밀도): **0.760 × 0.576 = 43.8%** (95% 35.4~54.2%)
   - P = FULL_FUNCTION(A' 와 같은 범위): **0.750 × 0.576 = 43.2%** (95% 33.9~55.2%). P(FULL) 36/48 은 커밋하지 않는 판정 파일에서 셌으므로 저장소 파일만으로는 재현되지 않는다
3. **게이트 2 의 A(60.0%, P(C | K))는 바꾸지 않는다.** 게이트 2 판정(ADR-016)은 사전 등록대로 test 100건 전체다. §10.6 은 게이트 판정이 아니라 논증이라 다른 분모를 쓴다. 두 값을 함께 적고, P × A = 45.6% 는 (a)(b) 에 독립 가정까지 든 근사로, **점추정 기반 Fréchet 범위** 36.0~60.0% 를 독립 가정 없는 범위로 적는다 (점추정을 넣은 범위라 표본 오차는 반영하지 않는다).
4. **적용 범위를 라벨 출처별로 적는다.** P × A' 는 `MODEL_LLM` 중 학습 20개 저장소 행에만 쓴다. `MODEL_ONLY` 는 val 52.0%(P(C | K))로 경우 2 범위(28.0~52.0%)만, `UNDISTINGUISHED`·`NOT_CLASSIFIED` 는 대상이 아니다. 신규 80개 저장소에는 P·A 어느 쪽도 쓰지 않는다.

## 이유

- 연쇄 법칙 P(M ∧ C | K) = P(M | K) · P(C | M, K) 는 참값끼리의 항등식이다. "P 와 A 가 독립이 아니다"(#129)라는 문제는 A 를 M 위의 조건부로 재면 없어진다 — 의존이 조건부 정의 안에 들어간다. 추정값의 곱이 근사로 남는 이유는 독립이 아니라 측정 범위다: M 판정 출처가 둘(필터 3인 판정 76.0% vs 라벨러 `filter-miss` 85.0%)이고, P 는 FULL + PARTIAL·저장소 비례, A' 는 FULL_FUNCTION·저장소 균등이다. 종류 범위는 P(FULL) 로 맞춘 값을 나란히 두고, 저장소 가중은 근거 문서 §4.4 에서 민감도로 본다.
- 경우 2 의 곱과 목표량의 차이는 P · (1 − P) · (A'' − A') 이다 (A'' = P(C | ¬M, K)). 곱은 하한도 상한도 아니고 부호는 분류기가 의미 없는 삭제를 얼마나 잘 맞히느냐에 달렸다. 이 데이터에서 A'' = 11/15 = 73.3% > A' 이라 P × A 가 1.8%p 과대다 — 독립 가정이 결과를 좋게 보이게 하는 쪽이다.
- 새 측정이 필요 없다. 커밋된 라벨·예측을 칸으로 나눌 뿐이고, test 에 분류기를 다시 돌리지 않는다 (§10.2 "최종 1회").

## 대안과 버린 이유

- **P × A(60.0%) 를 그대로 쓰고 "대략"으로 한정 (현행 v1.14)** — 독립 가정이 이 데이터에서 과대 쪽으로 작용한다는 것을 알면서 쓰는 셈이고, "왜 곱하나"에 답하지 못한다.
- **점추정 기반 Fréchet 범위(36.0~60.0%)만 보고** — 독립 가정은 없지만 폭이 24%p 라 논증으로 약하다. 경우 1 값을 셀 수 있는데 쓰지 않을 이유가 없다. 보조로 함께 적는다.
- **test 100건에서 직접 센 P(M ∧ C | K) = 49/100 = 49.0%** — P 가 필요 없지만 M 판정이 라벨링 중 2인이 부산물로 단 `filter-miss` 다(M 비율 85.0%). P 는 그 질문 하나를 3인이 따로 판정한 사전 등록 측정(76.0%)이다. 같은 기준인데 비율이 9%p 다르므로, M 은 사전 등록 측정 쪽을 쓰고 49.0% 는 점검값으로 적는다.
- **게이트 2 의 A 를 A' 로 바꾸기** — 사전 등록(ADR-016)을 결과를 본 뒤 바꾸는 것이다. 하지 않는다.
- **#89 정밀도 표본과 test 를 같은 표본으로 다시 재서 대조** — 새 수동 판정이 필요하고 test 를 다시 묻게 된다. 지금 라벨의 `filter-miss` 칸 나누기로 갈음한다.
