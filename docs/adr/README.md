# ADR (Architecture Decision Record)

설계 결정을 하나씩 파일로 기록한다. CHARTER.md §5에 요약된 ADR-001~011도 여기에 개별 파일로 옮긴다.

- 파일명: `NNN-짧은-제목.md` (예: `001-python-first.md`)
- 템플릿: `000-template.md`
- 스키마·분류 체계·파서 인터페이스·필터 규칙 버전·범위 변경은 §13 절차(이슈 → 회의 → ADR → CHARTER 갱신)를 따른다
- 시도했다가 버린 접근도 ADR로 남긴다: "시도 → 실패 이유 → 대안"
