## NOISE_MOVE 세부 규칙 (ADR-014, 2026-09-15)

**정규화 (AST, tree-sitter)**
- 식별자(변수명·파라미터명·지역 함수명) → `VAR`, 문자열 리터럴 → `STR`, 숫자 리터럴 → `NUM`
- 주석·독스트링 제거, 공백·들여쓰기 정규화
- 치환하지 않는다: 함수명 자체, 속성 접근과 호출 대상 이름 (`self.headers`, `json.loads` 등)

**유사도 (2단계)**
1. 정규화 본문이 완전히 같으면 이동
2. 아니면 `difflib.SequenceMatcher(None, 삭제_줄목록, 추가_줄목록, autojunk=False).ratio() >= 0.9`이면 이동
   - 비교 단위는 정규화 본문의 줄 목록, 인자 순서는 (삭제, 추가)로 고정

**후보 범위**
- 같은 커밋의 모든 추가 함수 (같은 파일·다른 파일 모두). 같은 파일 안에서 위치만 바뀐 이동도 이동이다
- 같은 경로의 수정은 후보에서 빼지 않고 임계값 0.9로 가른다. 단 줄 수의 10% 이하만 바꾼 수정과 식별자·리터럴만 바꾼 수정은 이동으로 판정될 수 있다 (ADR-014 결정 3 "한계")
- 1차 거르기: 정규화 본문 줄 수 차이가 긴 쪽의 20%를 넘으면 비교하지 않는다 (`(긴 쪽 − 짧은 쪽) / 긴 쪽 > 0.2`). 이 경우 비율 상한이 약 0.889라 0.9에 닿을 수 없다

임계값 0.9는 CHARTER §4.2 ② 값 그대로다. 구현 후 정밀도를 재측정한다 (§10.1).
