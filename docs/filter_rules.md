## NOISE_MOVE 세부 규칙 (ADR-014, 2026-09-15)

**정규화 (AST, tree-sitter)**
- 식별자(변수명·파라미터명) → `VAR`, 문자열 리터럴 → `STR`, 숫자 리터럴 → `NUM`
- 다른 함수의 본문에 포함된 중첩 함수 선언의 이름 → `VAR`
- 주석·독스트링 제거, 공백·들여쓰기 정규화
- 치환하지 않는다: 현재 비교 대상 함수의 이름(`Function.name`), 속성 접근과 호출 대상 이름 (`self.headers`, `json.loads` 등)
- 별도로 추출된 중첩 함수는 자신의 이름을 대상 함수 이름으로 취급해 보존한다

**유사도 (2단계)**
1. 정규화 본문이 완전히 같으면 이동
2. 아니면 `difflib.SequenceMatcher(None, 삭제_줄목록, 추가_줄목록, autojunk=False).ratio() >= 0.9`이면 이동
   - 비교 단위는 정규화 본문의 줄 목록, 인자 순서는 (삭제, 추가)로 고정

**후보 범위**
- 같은 커밋의 추가 함수 중 **파일 경로 또는 위치가 삭제 함수와 다른 것만** (다른 파일로의 이동, 같은 파일 안의 위치 이동)
- **같은 경로·같은 위치**의 추가 함수는 유사도 계산 전에 제외하고 수정으로 처리한다. "같은 위치"의 판정 기준(부모·자식 커밋 줄 번호 대응)은 #52에서 정해 이 문서에 반영한다
- **정규화 본문이 0줄인 함수는 이동 후보에서 제외한다** (1차 거르기의 0으로 나누기와 빈 본문끼리의 일치를 막는다)
- 위치를 옮기면서 줄 수의 10% 이하만 바꾸거나 식별자·리터럴만 바꾼 함수는 이동으로 판정된다 (ADR-014 결정 3 "한계")
- 1차 거르기: 정규화 본문 줄 수 차이가 긴 쪽의 20%를 넘으면 비교하지 않는다 (`(긴 쪽 − 짧은 쪽) / 긴 쪽 > 0.2`). 이 경우 비율 상한이 약 0.889라 0.9에 닿을 수 없다

임계값 0.9는 CHARTER §4.2 ② 값 그대로다. 정밀도는 #52 구현 PR에서 재측정한다 (§10.1).
