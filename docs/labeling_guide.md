# 이유 라벨링 가이드

버전: v0 (작성 예정). 담당: 성제 (1주차 과제, CHARTER.md §6.1). 라벨링은 사람이 한다. LLM은 후보 제안까지만 (ADR-005).

## 이유 8종 (CHARTER.md §4.2 ③, 그대로 사용)
BUG / PERF / SEC / LIB / DEAD / DESIGN / FEAT / UNK

## 근거 등급 (모든 레코드 필수)
EXPLICIT (원문 인용) / INFERRED (추론 근거 + 신뢰도 0~1) / UNKNOWN

## 작성할 내용
- 라벨별 판정 기준과 경계 사례
- 복수 이유가 겹칠 때 우선순위
- 근거 등급 판정 절차
- 교차 검증 방법과 일치도(kappa) 계산
- 예비 200건(2주차, 게이트 1) → 500건(5주차) 배분 계획
